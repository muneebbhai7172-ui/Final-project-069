How the Color System Works

  • Page Background: Lightest tinted shade - provides subtle color context
  • Sidebar Background: Medium shade - darker than page, lighter than primary
  • Card/Form Backgrounds: White or very light - maximum readability
  • Table Headers: Use sidebar color for grouping
  • Borders: Use secondary color for subtle separation
